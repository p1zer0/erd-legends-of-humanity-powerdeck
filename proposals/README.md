# Vorschläge

Was der Verbesserungs-Loop gefunden hat. Jeder Vorschlag liegt zweimal vor:

- `*.md` — zum Lesen: Begründung, Belege, Prüf-Checkliste
- `*.json` — zum Übernehmen: `python3 -m powerdeck loop --anwenden <datei>.json`

**Nichts hier ist übernommen, bis es jemand übernommen hat.** Vorschläge zu
`data/roster.json` sind prüfpflichtig und brauchen zusätzlich `--bestaetigt`:
sie enthalten Aussagen über reale Personen und Organisationen.

Erledigte Vorschläge dürfen gelöscht werden — sie stehen in der Git-Historie.
